# Data

Raw and processed thesis data are not included in this repository due to publication, privacy, and data-sharing restrictions.

This repository is intended to demonstrate the analytical structure and coding logic of the workflow. Users can adapt the scripts to public datasets such as GEO, TCGA, or other open-access single-cell and bulk transcriptomic resources.

No patient-level identifiers, unpublished sample-level metadata, raw count matrices, processed Seurat objects, or project-specific intermediate files are provided.
